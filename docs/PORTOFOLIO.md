# FitCoach AI

## Ringkasan Project

FitCoach AI adalah asisten digital untuk kebugaran dan nutrisi yang dirancang untuk memberikan panduan yang mudah diakses, personal, dan praktis dalam menjalani gaya hidup sehat. Aplikasi ini menggabungkan antarmuka web modern dengan backend berbasis AI agar pengguna dapat merencanakan menu makanan, memperbaiki kebiasaan latihan, dan mendapatkan saran kesehatan yang relevan melalui percakapan interaktif.

## Mengapa Proyek Ini Penting

Platform ini menjawab kebutuhan akan layanan kesehatan yang ringan, terjangkau, dan mudah dipraktikkan. Alih-alih hanya mengandalkan informasi statis, pengguna dapat bertanya secara natural dan menerima jawaban yang terstruktur sesuai kebutuhan terkait kebugaran, nutrisi, hidrasi, dan rutinitas harian.

## Fitur Utama

- Konsultasi kesehatan berbasis AI dalam Bahasa Indonesia
- Perencanaan menu dan saran nutrisi
- Rekomendasi latihan untuk rutinitas di rumah
- Analisis multimodal untuk gambar, dokumen, audio, dan video
- Respons chatbot real-time dengan streaming
- Panduan BMI dan kebutuhan kalori
- Riwayat chat yang tersimpan secara lokal

## Stack Teknologi

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Integrasi AI: Gemini API
- Upload Media: Multer
- Runtime: Node.js

## Highlight Implementasi

- Antarmuka yang responsif dan mudah digunakan
- Server Express untuk orkestrasi API dan validasi input
- Dukungan upload file untuk analisis kesehatan multimodal
- Streaming respons untuk pengalaman chat yang lebih alami
- Persistensi sesi lokal untuk pengalaman yang lebih baik

## Ruang Lingkup Proyek

Proyek ini berperan sebagai prototipe asisten kesehatan berbasis AI dengan potensi pengembangan yang besar menjadi aplikasi produksi, seperti pelacakan profil pengguna, analitik kebugaran, dan personalisasi kesehatan yang lebih maju.
